# RNBP-013: Blueprint canvas UX, devices and metadata

**Phase:** UX  
**Priority:** P2  
**Status:** TODO  
**Depends on:** RNBP-002, RNBP-003

## Objective

Turn the extracted canvas into the focused Blueprint View product surface.

## Scope

- Pan and zoom controls with sensible bounds and reset.
- Artboard selection/focus.
- Device viewport presets plus custom dimensions.
- Screen/variant grouping.
- Screen metadata display.
- Layout behaviour for large screen sets.
- Keyboard/mouse interactions on web where appropriate.

## Acceptance criteria

- Dozens of registered artboards remain navigable without manual source changes.
- Users can zoom, pan, focus and reset the canvas.
- Viewport size is manifest-driven and visible.
- Variants can be visually grouped under their screen.
- Selected screen metadata can be inspected without coupling to a navigation adapter.
- Interaction tests cover core canvas controls.
